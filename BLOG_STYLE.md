# Стиль и структура SEO-постов блога Яндекс KIT

Пишем для людей. SEO-ключи встраиваем естественно, без «набивки» в каждом предложении.

## Формат content в API

Редактор KIT (TipTap / MarkdownInput) хранит **Markdown**, не HTML и не «голый» plain text.

- `## Заголовок` — секции (H2; H1 — в поле seo_h1 / title)
- `**жирный**` — B
- `_курсив_` — I
- `* пункт` или `*   **Пункт.** текст` — маркированный список
- `[текст](https://...)` — ссылки на каталог/товары
- Абзацы через пустую строку
- **Не передавать HTML** (`<p>`, `<h2>`, `<strong>`…) через API — в редакторе поле станет пустым

Эталон: статья «Постельное белье…» после ручного/UI-сохранения (см. content в API — с `##` и `**`).

## Обязательная структура каждой статьи

1. **Живой заход (1–2 абзаца)**  
   Сцена или узнаваемая проблема: полиняло, село, скользит, «взяли на глаз». Не энциклопедическое вступление.

2. **Мини-история / типичная ошибка**  
   Короткий кейс покупателя (1 абзац), чтобы человек узнал себя.

3. **Кому что подходит**  
   Не сухой список терминов, а сценарии выбора (жарко спите / не гладите / нужен отельный вид и т.д.).

4. **Конкретика и чек-лист**  
   Что смотреть на ярлыке, швах, размере; 4–7 пунктов «проверьте перед покупкой».

5. **Практический блок по теме**  
   Размеры, уход, сравнение вариантов — с пользой, без воды.

6. **FAQ (3–4 вопроса)**  
   Короткие ответы на частые сомнения.

7. **Мягкий переход к полке товаров**  
   1–2 предложения: подобрать в подборке ниже / оформить заказ с доставкой.

## Тон

- Магазин домашнего текстиля: тепло, уверенно, по делу.
- Обращение на «вы».
- Без канцелярита («осуществляется», «данный продукт»).
- Ключ темы из таблицы (колонка C) упомянуть естественно в title/seo и 2–4 раза в тексте, не чаще.

## Поля статьи

- `title`, `short_description`, `slug`, `seo_title`, `seo_h1`, `seo_description`, `tags`
- Обложка с каталога магазина (не из колонки B таблицы)
- `attachment`: CATEGORY или COLLECTION под тему
- `status`: ACTIVE

## После публикации

В Google Таблице (лист 36) залить **только колонку C** использованной темы цветом как у C1 (`backgroundColor: { green: 1 }`).
